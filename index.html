Project spotlight

ESP32 Weather Stack

A personal end-to-end weather-monitoring project where I designed and built a small ESP32-based stack, then documented the work as a structured technical report rather than leaving it as an isolated prototype.

  • ESP32
  • IoT
  • Embedded integration
  • Data reporting
  • System design
View repository

What I built

A compact weather-monitoring stack that brings together ESP32-based data collection, the surrounding software needed to work with the readings, and a report that explains the system clearly from setup through results.

Technologies and problem solved

The project sits across embedded and software concerns: ESP32, sensor integration, IoT-style data capture, repository-based documentation, and the tooling needed to turn hardware output into something inspectable and reportable.

It solves the practical problem of collecting environmental data in a lightweight, self-contained way, while also turning raw readings into something that can be understood, reviewed, and communicated beyond the device itself.

What I learned and what was hard

The work reinforced how different embedded projects feel from pure web delivery: hardware constraints surface quickly, observability matters more, and good reporting is part of the engineering work rather than an afterthought.

The harder part was not just getting readings from a device, but making the whole stack coherent: connecting hardware behaviour, data flow, and explanation into a system that is reliable enough to demonstrate and detailed enough to present.
